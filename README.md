# Онлайн-кинотеатр «Космос»

## Описание

Информационная система для онлайн-покупки билетов в кинотеатр «Космос»: афиша,
выбор сеанса и места на схеме зала, бронирование, личные билеты, а также
администрирование афиши, расписания и отчёт о продажах.

Учебный проект по учебной практике (УП, 2026).

## Технологии

- Python 3.12, Flask 3.1, Jinja2;
- SQLite 3 (файл `src/db/project.db`);
- pytest 9 + pytest-cov (33 автотеста, покрытие 86 %);
- flake8, radon (метрики сложности и стиля);
- Git / GitHub, VS Code, Draw.io.

## Как запустить

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Derubs/cinema-kosmos.git
cd cinema-kosmos

# 2. Создать виртуальное окружение и установить зависимости
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt

# 3. Создать и наполнить базу данных (если файла project.db нет)
python -m src.db.seed_db

# 4. Запустить приложение
python run.py
```

Приложение откроется по адресу <http://127.0.0.1:5000>.
