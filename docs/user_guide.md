# Руководство пользователя

Онлайн-кинотеатр «Космос» — веб-приложение для покупки билетов в кинотеатр.
Руководство рассчитано на двух пользователей: **клиента** (зрителя) и
**администратора** кинотеатра.

## 1. Запуск

1. Откройте терминал в папке проекта.
2. Выполните `python run.py`.
3. Откройте в браузере <http://127.0.0.1:5000>.

Стартовая страница — афиша с ближайшими сеансами. В шапке сайта расположены
разделы «Афиша», «Мои билеты» (после входа), «Админ-панель» (только для
администратора), кнопки «Вход» и «Регистрация».

## 2. Регистрация и вход

1. Нажмите **Регистрация**, заполните ФИО, логин и пароль (не короче 4 символов).
2. Нажмите **Зарегистрироваться** — появится сообщение об успехе.
3. Нажмите **Вход**, введите логин и пароль, нажмите **Войти**.

Если пароль неверный, система покажет сообщение «Неверный логин или пароль»
и останется на странице входа. Пароли хранятся в базе в виде хеша SHA-256.

## 3. Покупка билета (основной сценарий)

1. На главной странице выберите фильм и нажмите **Купить билет** у нужного сеанса.
2. На схеме зала зелёные места свободны, красные — заняты.
3. Нажмите на свободное место — бронь создаётся сразу.
4. Появится сообщение «Билет №… оформлен: ряд …, место …».
5. Откройте **Мои билеты**, чтобы увидеть свои брони.

Если место уже занято, появится сообщение «Место уже занято», а схема зала
обновится — выберите другое место.

## 4. Отмена брони

1. Откройте **Мои билеты**.
2. Нажмите **Отменить** у нужного билета.
3. Появится сообщение «Бронь отменена», место снова станет свободным.

Клиент может отменить только свою бронь; администратор — любую.

## 5. Работа администратора

### 5.1. Афиша

1. Войдите как `admin`.
2. Откройте **Админ-панель** — на ней видны количество фильмов, сеансов,
   действующих билетов и выручка.
3. Раздел **Афиша (фильмы)** — список фильмов с кнопками **Изменить** и **Удалить**.
4. Кнопка **Добавить фильм** открывает форму: название, жанр, длительность,
   возрастной рейтинг, описание. Все поля, кроме описания, обязательны.
5. После сохранения фильм появляется в афише.

Фильм, у которого есть сеансы, удалить нельзя: система покажет сообщение
«Нельзя удалить фильм: у него есть сеансы в расписании».

### 5.2. Расписание

1. Откройте **Расписание (сеансы)**.
2. Нажмите **Добавить сеанс**, выберите фильм, укажите дату и время, зал и цену
   (цена должна быть больше нуля).
3. Для удаления сеанса нажмите **Удалить** — сеанс удаляется вместе с билетами.

### 5.3. Отчёт о продажах

Раздел **Отчёт о продажах** показывает все билеты: клиента, фильм, время,
зал, место, цену и статус, а также сводку по выручке.

## 6. Ошибки и ограничения

| Ситуация | Что увидит пользователь |
|---|---|
| Неверный логин или пароль | «Неверный логин или пароль» |
| Пустая форма | «Заполните все поля формы» |
| Короткий пароль | «Пароль должен содержать не менее 4 символов» |
| Занятое место | «Место уже занято» |
| Удаление фильма с сеансами | «Нельзя удалить фильм: у него есть сеансы» |
| Чужой билет | «Не удалось отменить бронь: билет не найден или принадлежит другому пользователю» |
| Несуществующая страница | страница «Страница не найдена» (404) |
| Доступ к админке клиентом | страница «Доступ запрещён» (403) |

Ошибки сервера записываются в файл `app.log` в корне проекта.
